Инструкция по компиляции проекта
Необходимо с офицального сайта скачать JDK

1. Создайте файл manifest.txt для манифеста JAR-файла:
   Напишите внутри манифеста: 
   Manifest-Version: 1.0
   Main-Class: Main

   В конце файлы отступите одну строчку.
   Потому что пустая строка даст парсеру JDK понять что ваш манифест завершен.

   Можете перейти в терминал вашей IDE или открыть командную строку вашей операционной системы.

2. Перейдите в корень проекта, например cd C:\Users\Crying\IdeaProjects\MyApp

3. Компилируйте исходники в папку out: javac -d out src\Main.java
   Опция -d out создаёт папку out и складывает туда скомпилированные .class файлы.
   
4. Используем команду jar: jar cfm MyApp.jar manifest.txt -C out .
   c — создать JAR
   f — указать имя файла JAR
   m — использовать собственный манифест
  -C out . — добавить все файлы из папки out
  
   После выполнения команды появится файл: C:\Users\Crying\IdeaProjects\MyApp\MyApp.jar
  
5. Для запуска приложения используйте команду: java -jar MyApp.jar
